# Nine print model hub

Windows用のローカル3Dモデルライブラリ。STL・STEP/STP・3MF・OpenSCADファイルを登録し、一覧・検索・3Dプレビューを使えます。OpenSCADでは公開パラメータの調整、プリセットの保存、STL出力ができます。

このREADMEはv0.9.1の使い方を説明します。AIエージェントからの利用は [MCPの接続方法](docs/mcp.md)、開発は [AGENTS.md](AGENTS.md) と [設計・データの流れ](docs/architecture.md)、今後の仕様は [ロードマップ](docs/roadmap.md) を参照してください。

## 起動

配布版では `Nine print model hub.exe` を開きます。リポジトリ内で `npm run package` を実行した場合は `release/win-unpacked/` に生成され、`起動.cmd` から開けます。配布版を移動するときは **`win-unpacked` フォルダ全体**を移動します。配布版の実行にNode.jsは不要です。

アプリは登録したファイルを保存場所から参照します。OpenSCADによる形状計算とBambu Studioでの印刷準備は、それぞれインストール済みのアプリを使います。

## 基本操作

- **監視フォルダを追加**: サブフォルダも対象に、ファイルの追加・更新・削除・復帰を自動反映します。フォルダをドラッグ＆ドロップしても登録できます。起動時は保存済みの一覧を表示し、監視の初回走査結果で登録を照合します。
- **ファイルを追加 / ドロップ**: 個別ファイルを登録します。監視外の登録ファイルは、起動時と「再スキャン」で状態を確認します。自動反映が必要なら保存先を監視フォルダに追加してください。
- **3Dビュー**: 標準の軽量モードでは、選択後に「3Dプレビューを読み込む」を押して読み込みます。右クリックの「プレビュー」から直接開くこともできます。左ドラッグで回転、右ドラッグで移動、ホイールで拡大縮小。`F` で全体表示。
- **ライブラリ**: 1ページ48件。検索（`Ctrl+F`）、形式フィルタ、名前・更新日・サイズ順、グリッドとリスト、お気に入り、タグ、メモに対応。タグはカンマ区切りで入力して保存します。
- **モデルを右クリック**: 「プレビュー」「サムネイル生成」「指定先へコピー」「バンブースタジオで開く」「削除」を選べます。コピー先に同名ファイルがあれば中止します。「削除」は確認後に元ファイルをWindowsのゴミ箱へ移し、登録を外します。
- **移動・名前変更のあと**: 左の「ファイル不在」で旧モデルを選び、「元ファイルを再指定」から移動先を選びます。タグ、メモ、お気に入り、OpenSCADプリセットを引き継ぎます。移動先が監視で二重登録された場合は、移動先に独自データがないことを確認してから統合できます。
- **サムネイル生成**: 初回の3D表示でもサムネイルが保存されます。一覧上部のボタンから実行を確認すると、検索やフィルタに関係なく全登録を1件ずつ処理します。「未生成のみ」が初期値で、画像を更新するには「すべて再生成」を選びます。ファイル不在はスキップし、読み込みエラーや1件あたり90秒超過は失敗の詳細に残します。中止後は「未生成のみ」で保存済みの画像を再利用できます。元ファイルの更新や再紐付けで古い画像は無効になります。
- **Bambu Studioで印刷準備**: STL・STEP・3MFは元ファイルを、SCADは現在のパラメータから生成した一時STLをStudioへ渡します。以降のプレート・素材の設定、スライス、プリンタへの送信はStudioで行います。Studioが見つからないときは「設定と連携」で実行ファイルを選びます。
- **プレビューメモリ**: 標準の軽量モードは0.5 GiBの読込予算を使います。大きなモデルを3D表示するときは「設定と連携」で軽量モードをオフにし、0.5〜32 GiBの予算を指定できます。「設定を保存」は次回の読み込みに反映し、「保存して再読み込み」は現在のモデルを再試行します。
- **登録解除**: ライブラリからだけ削除し、監視での自動再登録を抑制します。「ファイルを追加」またはファイルのドロップで再登録できます。元ファイルは消しません。
- **監視解除**: フォルダの監視を解除しても、登録済みモデルは残ります。

## OpenSCAD

`.scad` ファイルを登録してプレビューや出力を実行すると、インストール済みのOpenSCADで元ファイルを計算します。OpenSCADが未検出なら「設定と連携」で実行ファイルを指定できます。相対指定の `include` や `import` もOpenSCAD側で解決されます。

「公開パラメータ」の値を変更してプレビューし、その設定でSTLへ出力できます。元のSCADは書き換えません。数値・真偽値・文字列・数値ベクトルのリテラルに対応します。`[Hidden]` や式で算出される内部値は入力欄に表示しません。

「プリセット名」を入れて保存すると、変更した値をモデルごとのSQLiteテーブルに記録します。選んだプリセットの適用・上書き・削除、OpenSCAD Customizer形式のJSON読み込み・書き出しができます。プリセットにない項目にはSCADの既定値が使われます。プレビューに反映するには「プレビューを更新」を押します。JSONにはプリセット名と公開パラメータの値だけを書き出します。

| STL出力モード | 出力内容 |
| --- | --- |
| 現在のモデル | パラメータ欄の値で1ファイル |
| 指定したパーツ | パーツ切り替えの選択肢を1つ指定 |
| 選択したパーツ | チェックした選択肢を1ファイルずつ |
| 全パーツ | パーツ候補を1ファイルずつ。組立・分解・確認用と判別できる表示候補は除く |

パーツ出力は、たとえば `part = "assembly"; // [assembly:Assembly, base:Base, lid:Lid]` のように、モデル自身が公開パラメータの選択肢を持つ場合に使えます。別名のパラメータもパーツ切り替えとして選べます。形状を解析して自動分割する機能ではありません。複数ファイルを出すときは、保存先を選んで順番に生成します。同名のSTLがあればその項目は失敗として記録します。

## 対応範囲

| 形式 | 表示 |
| --- | --- |
| STL | ASCII / binary。単位情報がないためmmとして表示 |
| SCAD | インストール済みOpenSCADで形状を計算し、3D表示。公開パラメータの編集とSTL出力に対応 |
| STEP / STP | OpenCascade WASMで表示用メッシュに変換。基本色・面色対応。編集用CADカーネルではありません |
| 3MF | メッシュ、部品構造、配置、単位、基本色・頂点色、Bambu方式の分割モデル参照。形状を表示できない場合は対応する内蔵画像を表示 |

Bambu / Orca独自のペイント色、テクスチャ、複合マテリアル、スライス済みツールパスの再現は未対応です。表示上の制約を画面に示し、元ファイルの印刷設定は保持します。複数プレートのモデルは、3MFの元の配置でまとめて表示します。

### プレビューの負荷と上限

軽量モードでは形状が使える段階でWebGLを初期化し、静止中の描画を止めます。明示プレビューでは256 KiB以上のSTLと3MFを専用ワーカーで解析し、STEPも別ワーカーで変換します。「読み込みを中止」やモデルの切り替えで処理を中断できます。

| 制限 | 標準の軽量モード | 実装上限 |
| --- | ---: | ---: |
| 入力ファイル | 64 MiB | 1 GiB |
| 3MFの単一XML | 32 MiB | 256 MiB |
| 3MFの展開合計 | 96 MiB | 2 GiB |
| 三角形 | 75万 | 2,400万 |

3MFの3D読み込みに失敗した場合は、標準ZIP内の対応するPNG・JPEGを範囲読み込みして表示します。保存済みの予算が軽量時の512 MiBより大きければ、「詳細上限で再読み込み」でそのプレビューに予算と詳細描画を適用できます。プレビュー上限を超えても、ライブラリ登録とBambu Studioへの受け渡しは使えます。

「設定と連携」で、軽量モードをオフにしたときの予算と対応する読み込み上限を確認できます。予算はファイルサイズや解析量の制限を調整します。OSが計測する実際のRAM使用量は、展開や描画で予算を上回る場合があります。

## 保存データ

通常は `%APPDATA%/Nine Model Library/library.sqlite3` に登録情報、監視フォルダ、タグ、メモ、サムネイル、設定、OpenSCADプリセットを保存します。名称変更後も同じフォルダを使います。旧版から切り替える際は旧版を終了してから新しい実行ファイルを開いてください。初回起動時に旧 `library.json` の内容を取り込み、旧ファイルを残します。DBが読めない場合は起動エラーを表示し、旧データへの自動巻き戻しは行いません。バックアップはアプリを完全に終了してから、このデータフォルダごとコピーしてください。

同じパスの二重登録は防ぎます。同一内容でも別の保存場所なら別モデルとして扱います。移動したモデルは「元ファイルを再指定」で旧登録に戻せます。移動先に独立したタグ、メモ、お気に入りやプリセットがある場合は、それぞれの登録を残します。

## 開発・検証

開発・テストには組み込みSQLiteを備えたNode.js 24以降とnpmを使います。このフォルダで実行します。

```text
npm ci
npm run dev
npm test
npm run build
npm run package
```

`npm run dev` はViteとElectronを起動し、`npm run package` は未署名のWindows用フォルダ形式アプリを作ります。`npm run build` の後、`node scripts/smoke.mjs` で表示・監視・保存を隔離データで実画面検証できます。配布版を検証するときは `--packaged` を付けます。機能の追加箇所と用途別の検証コマンドは [設計・データの流れ](docs/architecture.md) にまとめています。
